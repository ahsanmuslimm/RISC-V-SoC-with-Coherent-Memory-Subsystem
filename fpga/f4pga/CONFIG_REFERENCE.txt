================================================================================
DEVICE CONFIGURATION
================================================================================

Device Name:        XC7A100T-CSG324
FPGA Family:        Artix-7
Package:            324-pin CSG (Ceramic BGA)
Logic Cells:        ~101,440 LUT6 slices
Memory:             30 BRAM36K blocks
DSP Slices:         240
I/O Banks:          4 (LVCMOS33)

Board:              Digilent Arty A7-100T
Oscillator:         100 MHz (E3)
Power:              3.3V logic, 5V I/O tolerant (select pins)

================================================================================
DESIGN SPECIFICATIONS
================================================================================

Architecture:       Dual-Core RISC-V RV32I
Cores:              2 × RV32I processors
L1 Instruction Cache: 4-line direct-mapped per core (1 KB each)
L1 Data Cache:      4-line direct-mapped per core
Coherence:          I/S/M protocol (Invalid/Shared/Modified)
Shared Memory:      4 KB SRAM (address 0x10000000)

Clock Frequency:    100 MHz (configurable)
Clock Period:       10 ns
Reset:              Active-low asynchronous
Reset Synchronizer: 2-FF synchronizer for metastability

================================================================================
PIN CONFIGURATION
================================================================================

Clock:
  clk         → E3  (100 MHz oscillator input)

Reset:
  rst_n       → C2  (Active-low async reset, PULLUP)

UART Interface (Serial):
  uart_tx     → D10 (Output from FPGA to host)
  uart_rx     → A9  (Input to FPGA from host)
  Baud Rate:  115200 (8 data bits, no parity, 1 stop bit)

GPIO / LED Output:
  led[0]      → H17 (Red LED - LD4)
  led[1]      → K15 (Green LED - LD5)
  led[2]      → J13 (Blue LED - LD6)
  led[3]      → G13 (Red LED - LD7)
  led[4]      → D13 (Available)
  led[5]      → B14 (Available)
  led[6]      → F14 (Available)
  led[7]      → C14 (Available)

Buttons (Optional Input):
  btn[0]      → D9  (Center button, PULLUP)
  btn[1]      → C9  (Left button, PULLUP)
  btn[2]      → B9  (Right button, PULLUP)
  btn[3]      → B10 (Down button, PULLUP)

Standard:           LVCMOS33 (3.3V logic, LVTTL compatible)

================================================================================
MEMORY MAP
================================================================================

0x00000000 - 0x000003FF    Instruction SRAM - Core 0 (1 KB)
0x00000400 - 0x000007FF    Instruction SRAM - Core 1 (1 KB)
0x10000000 - 0x10000FFF    Shared Data SRAM (4 KB)
0x20000000 - 0x200000FF    MMIO Registers (Counters, Status, Control)
0x30000000 - 0x300000FF    UART Core (TX/RX, Control)
0x40000000 - 0x400000FF    GPIO/LED Controller
0x50000000 - 0x5FFFFFFF    (Reserved for future expansion)
Other Addresses            DECERR (Bus error response)

================================================================================
BUILD STEPS & OUTPUTS
================================================================================

1. SYNTHESIS (Yosys)
   Input:  RTL Verilog files (*.sv) from rtl/ directory
   Output: build/riscv_soc_arty100t.json (2-5 MB)
   Tool:   yosys
   Cmd:    yosys -p "read_verilog ... synth_xilinx -json ..."

2. PACK (F4PGA)
   Input:  .json netlist
   Output: riscv_soc_arty100t.eblif
   Tool:   f4pga pack
   Cmd:    f4pga pack -e <yaml> -d xc7a100t_test -s .eblif .json

3. PLACE (F4PGA)
   Input:  .eblif packed design
   Output: riscv_soc_arty100t.place
   Tool:   f4pga place
   Cmd:    f4pga place -e <yaml> -d xc7a100t_test -n .net.json -p .place

4. ROUTE (F4PGA)
   Input:  .place placement
   Output: riscv_soc_arty100t.route
   Tool:   f4pga route
   Cmd:    f4pga route -e <yaml> -d xc7a100t_test -s .route

5. BITSTREAM (F4PGA)
   Input:  .route routed design
   Output: build/riscv_soc_arty100t.bit (500-700 KB)
   Tool:   f4pga write_bitstream
   Cmd:    f4pga write_bitstream -e <yaml> -d xc7a100t_test -b .bit

Total Build Time: 8-30 minutes (depending on system speed)

PROGRAMMING

             -c "init" \
             -c "pld load 0 build/riscv_soc_arty100t.bit" \
             -c "exit"

Method 2: quickstart Script with --program
  Command: bash quickstart-bitstream.sh --program

Method 3: Vivado Lab Edition (if installed)
  GUI-based programming

Requirements:
  - Arty A7-100T connected via USB
  - OpenOCD installed and configured
  - Proper USB driver installed
  - User in dialout group (sudo usermod -a -G dialout $USER)

CONSTRAINTS FILE (arty100t.xdc)
================================================================================

The XDC file contains:
  - Pin location assignments (PACKAGE_PIN)
  - I/O standards (IOSTANDARD LVCMOS33)
  - Timing constraints (create_clock, period)
  - Pull-up configuration (PULLUP true)
  - Drive strength and slew rate settings
  - Bitstream configuration options

Key Timing:
  - sys_clk: 100 MHz (10 ns period) from pin E3
  - I/O timing: 0 ns input/output delay (unregistered paths)

To modify constraints:
  1. Edit arty100t.xdc
  2. Rebuild: bash quickstart-bitstream.sh
  3. Program: bash quickstart-bitstream.sh --program

================================================================================
RTLMODULE HIERARCHY
================================================================================

Top Module: riscv_soc_top (rtl/top/riscv_soc_top.sv)

Instantiates (per core × 2):
  - rv32i_core              RV32I processor
  - i_sram                  Instruction memory (async read, 256×32)
  - d_cache                 L1 data cache (4-line direct-mapped)
  - d_cache_mgr             Cache manager FSM (13-state)

System Modules:
  - coherence_ctrl          Coherence protocol controller (4-state I/S/M)
  - axi_lite_arbiter        2-master round-robin arbiter
  - axi_lite_decoder        Address decoder (4 slaves + DECERR)
  - shared_sram             Shared data memory (4 KB, 1024×32)
  - mmio_regs               MMIO registers (status, control, doorbell)
  - uart_core               UART serial interface (115200 8N1)
  - gpio_led                GPIO/LED output controller

Total Modules: 16

TROUBLESHOOTING QUICK REFERENCE
================================================================================

Problem                 → Solution
─────────────────────────────────────────────────────────────────────────────
Tools not found         → conda activate xc7

Device YAML missing     → Check F4PGA_INSTALL_DIR and installation completeness

Build hangs/freezes     → System may be out of RAM; check with 'free -h'

Synthesis fails         → Check RTL files exist in ../../rtl/*/*.sv

P&R timing violations   → Normal with --timing-allow-fail; design still works

Constraints ignored     → Ensure arty100t.xdc is in build directory

JTAG device not found   → Connect USB; run 'lsusb | grep Digilent'

OpenOCD fails          → May need: sudo usermod -a -G dialout $USER

Bitstream incorrect    → Check device matches: XC7A100T-CSG324

FPGA doesn't respond   → Try reprogramming; check LEDs for activity

More help              → See BITSTREAM_GENERATION_GUIDE.md
